01

우리의 미션과 공동 작업 약속

선생님이 준비한 20장 중, 내게 배정된 한 장을 완성해요.

한 장에 담을 것

눈에 띄는 제목, 핵심 정보 3개 안팎, 정보를 설명하는 그림·그래프, 한 줄 결론, 출처.

정보를 보이게!

긴 글을 그대로 붙이지 않아요. 비교는 막대, 순서는 화살표, 특징은 그림과 핵심어로 바꾸어요.

내 페이지만 편집

친구의 글·그림을 수정하거나 지우지 않아요. 페이지 추가·삭제·이동과 디자인 크기 변경도 하지 않아요.

시작 전에 담당 페이지 번호를 꼭 확인!
표지 등이 있으면 페이지 순서와 이름표가 다를 수 있어요. 번호가 헷갈리거나 친구와 겹치면 선생님께 확인해요. ‘모든 페이지에 적용’은 누르지 않아요.
02

큰 주제를 작은 질문으로

‘환경’보다 ‘교실의 일회용품을 어떻게 줄일까?’가 좋아요.

궁금한 주제 카드를 눌러 보세요.

탐구 질문, 조사 방법, 어울리는 표현 방법을 알려 줄게요.

이 세 가지에 ‘네’라고 답하면 좋은 주제!
① 내가 궁금한가?　② 믿을 만한 자료를 찾거나 직접 조사할 수 있는가?　③ 한 장으로 설명할 수 있는가?
03

꾸미기 전에, 내용부터 준비해요

주제 → 조사 → 핵심 메시지 → 배치 순서로 생각해요.

자료 조사 4가지 원칙

  1. 누가 만들었는지 확인. 공공기관, 교과서, 도서관 자료처럼 만든 곳이 분명한 자료를 찾아요.
  2. 숫자의 조건도 함께 기록. 조사 연도, 지역, 대상, 인원, 단위를 적어요.
  3. 내 말로 짧게 정리. AI의 답이나 검색 요약만 믿지 말고 원래 자료를 열어 확인해요.
  4. 출처를 바로 메모. 기관·자료 제목·발표 연도·주소를 남겨요. 직접 조사했다면 날짜·인원·질문을 적어요.

설문은 이름 없이 하고, 친구의 성적·건강·가정 형편 같은 민감한 정보는 묻지 않아요.

정보에 맞는 표현 고르기

크기·개수 비교 → 막대그래프
예: 등교 방법별 학생 수

시간에 따른 변화 → 꺾은선그래프
예: 월별 평균 기온

전체 중 비율 → 원그래프
합계가 100%인지 확인해요. 여러 개를 고르는 설문에는 함부로 쓰지 않아요.

과정·순서 → 화살표 / 특징 → 그림+핵심어
예: 물의 순환 / 기후별 생활 모습

그래프에는 제목·단위를 쓰고, 막대그래프는 원칙적으로 0부터 시작해요. 그림 크기로 차이를 과장하지 않아요.

나의 한 장 기획 메모

여기에 쓴 내용은 캔바로 자동 전달되지 않아요. 필요한 내용을 복사해 내 페이지에 옮겨요. 새로고침하거나 창을 닫으면 메모가 사라지니 먼저 TXT로 저장하세요.

04

공유된 캔바에서 내 한 장 만들기

새 디자인을 만들지 않고, 선생님이 보내 준 링크로 시작해요.

1

공유 링크로 들어가기

선생님이 안내한 계정으로 접속해요. ‘보기 전용’이거나 수정할 수 없다면 선생님께 알려요.

2

내 담당 페이지 찾기

페이지 목록이나 격자 보기에서 번호·이름표를 확인해요. 내 페이지를 선택하고 시작해요.

3

한 장의 배치 정하기

제목·그림·핵심 정보·결론·출처가 들어갈 자리를 생각해요. 선생님이 준 틀과 슬라이드 크기를 유지해요.

4

제목과 짧은 글 넣기

기존 글 상자를 선택해 고치거나 텍스트 메뉴로 추가해요. 제목은 크고 분명하게, 설명은 핵심어 중심으로 써요.

5

그림과 그래프 넣기

요소에서 아이콘·도형·화살표를 찾아요. 그래프는 ‘차트’를 검색하거나 차트 메뉴를 찾아 넣고, 예시 숫자를 내가 조사한 수치로 바꿔요.

6

색과 간격 정리하기

주요 색은 2~3개, 글꼴은 1~2개로 정리해요. 글과 배경이 잘 구별되게 하고 빈 공간을 남겨요. 위치·정렬 기능이 보이면 활용해요.

7

출처 쓰고 저장 상태 확인

아래쪽에 출처를 넣어요. 저장 완료 표시를 확인한 뒤 선생님이 정한 방법으로 완료를 알려요. 기본 제출물은 공유 디자인 안의 내 페이지예요.

계정·기기·화면 버전에 따라 메뉴 이름과 위치가 다를 수 있어요. 왕관·유료 표시나 사용 제한이 보이면 사용 가능한 다른 요소를 골라요.

공동 슬라이드에서 특히 조심!
  • 전체 테마·스타일을 바꾸지 않아요.
  • 템플릿의 ‘모든 페이지에 적용’을 누르지 않아요.
  • 다른 페이지를 실수로 바꾸면 계속 조작하지 말고 선생님께 바로 알려요.
  • 친구의 얼굴·이름·개인정보를 허락 없이 넣지 않아요.
파일로 따로 제출하라고 하셨다면?

선생님이 지정한 형식으로 내려받아요. 공유·다운로드 메뉴에서 페이지 선택을 내 담당 페이지로 지정하고 미리보기를 확인해요. 전체 20장을 내려받지 않도록 조심해요.

친구의 페이지를 참고해도 되나요?

배치 아이디어는 참고할 수 있지만 글·그림을 마음대로 가져오거나 직접 고치지 않아요. 의견은 말이나 선생님이 허용한 댓글로 전해요.

05

완성! 친구가 이해할 수 있을까?

예쁜 장식보다, 정확하고 쉽게 전달되는지가 중요해요.

제출 전 체크리스트 0 / 8

하나씩 확인하며 체크해 보세요.

짝과 30초 확인하기

  1. 무엇을 알려 주는 자료 같아?
  2. 가장 기억에 남는 정보는 뭐야?
  3. 잘 안 읽히거나 궁금한 부분이 있어?

친구가 이해하지 못한 곳을 한 가지 이상 고쳐요.

발표는 이렇게

“제 주제는 ___입니다.
___이 궁금해서 조사했습니다.
자료에서 ___을 알게 되었습니다.
그래서 ___이라고 전하고 싶습니다.”

선생님용 · 수업 운영 제안

1차시: 예시 읽기 → 주제 선택 → 자료 조사·기획 메모
2차시: 담당 페이지 제작 → 짝 피드백 → 수정·공유

시작 전에 20장 각각의 담당 학생 또는 모둠, 주제 범위, 제출 기한을 안내해 주세요. 인원이 20명을 넘으면 일부 페이지를 짝 활동으로 배정할 수 있습니다. 평가 초점은 정보의 정확성, 핵심 메시지, 시각적 전달, 출처 표시, 공동 작업 약속입니다.
